# Spring Boot AWS RDS Demo

A Spring Boot application demonstrating how to connect a Java backend application to an Amazon RDS MySQL database.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Amazon RDS (AWS)
- Maven

## Key Concepts
- Connecting Spring Boot to a cloud-hosted database
- Configuring database connectivity
- Understanding JDBC and JPA integration
- Working with persistent data using MySQL

## Configuration
Update `application.properties` with your Amazon RDS endpoint and database credentials.

**Note:** Never commit database passwords or other sensitive credentials to GitHub.

## Run the Application
```bash
./mvnw spring-boot:run
```

## Purpose
This project demonstrates practical experience integrating Spring Boot with AWS RDS for cloud-based database management.
